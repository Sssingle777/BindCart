BindCart 操作说明

打开作品
1. 从提交文件夹进入“作品源码/BindCart”，Windows 双击 Start-Windows.cmd，macOS 双击 Start-Mac.command。
2. “作品源码/BindCart”已经包含源码、Node 运行时及依赖；无需安装 Node、npm 或 Java。打开介绍页后点击“进入交互演示”。
3. 可先运行对应 Check 脚本检查文件与关键流程。停止时运行对应 Stop 脚本。
4. 如果使用不带运行时和依赖的纯源码副本，保留 BindCart 完整结构，安装 Node.js 22.13+，在 app 内执行 npm ci、npm run check、npm start。
5. 包内不含原作品运行状态。新订单、密钥和账本由该副本自行生成。

购物与认证
1. 在商城选择商品、加入购物车并点击结算。
2. 在控制台按“下一步”依次准备凭证、取得挑战、派生 VC、请求设备签名、生成联合证明、提交 B 验证。
3. 资格核验通过后，在商城支付窗口核对订单并确认本笔付款。
4. 在控制台同步用户授权，逐步完成付款前复核和钱包签名。
5. 完成结算认证，检查成功回执，再确认商户订单。商城显示订单成功提交。

查看证据
展开“验证者 B 的检查结果”查看各阶段的检查记录。成功回执显示交易哈希、金额、交易状态和收付款账户。可查询同一订单的回执，核对交易哈希与支付执行次数。

安全实验
在购物车阶段展开“验证实验”，分别点击“复制凭证实验”和“撤销凭证实验”。每项先执行合法对照，再执行实验请求；页面展示预期与实际原因码、拒绝位置、支付执行次数变化和余额检查。实验不执行付款。
