ShoppingAuth · 浅色视觉修复版
2026-10-20 · 基于已交付浅科技蓝版 / ShoppingAuth 0.5.0

请完整解压整个 ZIP，再打开其中的 ShoppingAuth 文件夹。
Windows：双击 Start-Windows.cmd。
macOS：双击 Start-Mac.command。若没有执行权限，可在终端使用 bash 加脚本路径启动。
启动器会先打开 AGENT TRUST 技术介绍页，点击“进入交互演示”进入原商城与认证控制台。
停止服务：双击对应的 Stop-Windows.cmd / Stop-Mac.command。
只关闭浏览器不会停止服务；再次启动会复用当前服务。

运行时与依赖随包提供，不需要安装 Node、npm、Java，也无需外部支付账号。
原便携演示采用独立 Node 软件 eSIM 与本地 TEST_USDC 测试链；无真实资金价值。
这里“不需要 Java”指便携版双页演示；开发源码中的旧 JavaCard 测试另外需要局部 JDK。
Windows x64 已实际运行。macOS arm64/x64 启动脚本与运行时保留，本轮未在 Mac 实机运行。

访问路径：
介绍页：本机服务地址 /intro/
原演示页：同一地址 /demo/
端口由启动器自动选择，不固定。
不要直接双击 app/public/intro.html 或 dual.html；应通过启动器使用本地服务。
直接访问没有启动凭据的介绍页可以浏览内容，进入交互演示时会提示运行启动器。

完整交互顺序：
1. 浏览介绍页，点击“进入交互演示”。
2. 商城选购 → 购物车 → 前往结算。
3. 认证控制台逐条执行凭证准备、挑战、派生凭证、设备贡献、组合证明、验证、提交授权申请。
4. 商城窗口明确批准当前订单；回到控制台逐步同步授权、付款前复核、钱包签名、结算验证。
5. 结算回执返回后，执行“核对商家并确认订单”。
每次点击只推进原有一个步骤；介绍页不发起任何密码学或支付操作。
挑战过期时按控制台提示重新获取挑战。结果未知时查询原交易，不要重复转账或删除运行状态。
